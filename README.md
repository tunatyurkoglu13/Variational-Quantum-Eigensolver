# VQE on NISQ Devices: A Comparative Study of Ansatze and Error Mitigation

> Status: Phase 0 (environment setup) in progress. This README is a placeholder and will be replaced with the full project summary, key finding, and quick-start instructions in Phase 8.

## Research question

Under what conditions is chemical accuracy (|ΔE| < 1.6 mHa) achievable for small molecules on NISQ (Noisy Intermediate-Scale Quantum) devices via the Variational Quantum Eigensolver (VQE), and what is the dominant limiting factor: ansatz expressibility, optimizer noise-robustness, or hardware error rate?
